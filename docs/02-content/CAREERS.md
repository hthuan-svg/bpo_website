# Careers Content Specification

Page:
`careers.html`

## Job list

Each job should have:
- title
- location if officially provided
- department if officially provided
- published/open date
- closing date if officially provided
- status
- description
- requirements
- application method

## Sorting

Newest jobs first.

## Status

Exactly:
- `Đang mở`
- `Đã đóng`

Status should be data-driven.

## No invented data

If no approved job information exists, show an intentional empty state rather than fake vacancies.

## Recruitment source

Remove recruitment content from Team.
