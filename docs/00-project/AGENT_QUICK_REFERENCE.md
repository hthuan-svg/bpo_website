# Agent Quick Reference

## Before
- Read `AGENTS.md`
- Read relevant docs
- Inspect actual implementation

## Do
- Minimal change
- Reuse existing architecture
- Keep content data-driven
- Keep image slots
- Validate

## Don't
- Framework migration
- Invent business data
- Fake email
- Delete placeholders
- Commit git

## After
- Inspect diff
- Test
- Update TASKS
- Update CHANGELOG
- Report:
  1. Files created/changed
  2. How to verify
  3. Assumptions
  4. Open issues
- Stop
