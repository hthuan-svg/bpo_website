# Agent Prompt Runbook

These files are intended to be run one at a time in Agent mode.

## Rules

- Read `AGENTS.md` first.
- Never paste all prompts into one request.
- Start with `00-AUDIT.md`.
- Audit makes no code changes.
- After each implementation prompt, inspect the diff and test.
- Update TASKS and CHANGELOG.
- Stop after each phase.
