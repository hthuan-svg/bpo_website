# Components

## Global

### Theme Toggle
- Dark default
- Light alternative
- accessible label
- persistent preference if supported

### Header
- brand lockup
- main navigation
- language switcher
- theme toggle
- mobile navigation

### Footer
Must contain:
- company/contact information
- office/address area
- navigation where appropriate
- legal/privacy links where available

## Image Placeholder

Use for planned images that are not yet available.

Expected behavior:
- subtle border/dashed frame
- correct aspect ratio
- no broken-image icon
- clear internal class/slot identification during development if needed
- accessible text only when appropriate

## Image Carousel / Running Strip

Use for:
- Home service/product gallery
- service category image strips

Requirements:
- horizontal presentation
- responsive
- keyboard-accessible controls if interactive
- reduced-motion support
- graceful fallback if only one image exists

## Timeline

For company history:
- years displayed above images
- years aligned horizontally on desktop
- responsive stacking on small screens
- preserve the body/content position specified by the existing page

## Stat Card

Home stats:
- label
- value
- image slot

Do not force a number where the official number is unknown.

## Status Badge

Careers:
- `Đang mở`
- `Đã đóng`

Use visual distinction and text, not color alone.

## Office Card

Show:
- office type
- address
- map action

No obsolete Phạm Văn Đồng address.
